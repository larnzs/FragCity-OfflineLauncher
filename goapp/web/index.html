Run this on the PC hosting CS2. The relay binds to your LAN interface and forwards UDP datagrams to the local server. Public source IPs are rejected.

Allow the forwarding UDP port in Windows Firewall on the Private network profile. Do not create a public router port-forward for LAN-only use.
